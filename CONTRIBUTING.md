# Contributing to SQLUMEN

Thank you for your interest in contributing.

SQLUMEN aims to become a high-quality educational and developer tool. Every contribution should improve correctness, maintainability, or usability.

---

# Ways to Contribute

You can contribute by

- Fixing bugs
- Improving documentation
- Adding parser support
- Improving graph layouts
- Writing tests
- Improving accessibility
- Suggesting optimization rules
- Improving UI
- Reporting bugs

---

---

# Coding Standards

- TypeScript Strict Mode
- No `any`
- Pure functions where possible
- ESLint required
- Prettier required
- Public APIs documented

---

# Pull Requests

Every PR should include

- Description
- Screenshots (if UI)
- Tests
- Documentation updates

---

# Reporting Bugs

Please include

- SQL query
- Expected result
- Actual result
- Dialect
- Screenshots
- Error logs

---

# Feature Requests

Clearly describe

- Problem
- Proposed solution
- Alternatives considered

---

# Code of Conduct

Be respectful.

Constructive feedback is encouraged.

Harassment or abusive behavior will not be tolerated.

---

Thank you for helping improve SQLUMEN.
