# Sample Schema

The shared fixture schema uses a realistic e-commerce domain:

- Users
- Addresses
- Orders
- Order_Items
- Products
- Categories
- Suppliers
- Warehouses
- Inventory
- Payments
- Refunds
- Shipments
- Reviews
- Coupons
- Employees
- Departments

## Schema Coverage

The DDL includes:

- Primary keys
- Foreign keys
- Indexes
- Unique constraints
- Check constraints
- Representative nullable and non-nullable columns

## Uses

This schema supports:

- ER and graph examples
- Join and aggregation fixtures
- CTE and recursive-query fixtures
- AI context examples
- EXPLAIN examples
- Test-data generation

The fixture must remain dialect-aware. Portable definitions should be shared, while dialect-specific DDL should be documented separately.
