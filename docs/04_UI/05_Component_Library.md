# Component Library

Reusable components provide the shared UI language across supported application surfaces.

## SQL Editor

Monaco wrapper with syntax highlighting, diagnostics, source selection, and dialect context.

## Graph Canvas

React Flow wrapper with layout, zoom, pan, mini map, selection, and keyboard support.

## Node Card

Reusable node UI with type styling, labels, metadata, warning indicators, and focus states.

## Statistics Card

Shows table, join, CTE, aggregate, window, and complexity metrics.

## Warning Card

Displays query smells, severity, explanation, source location, and remediation guidance.

## Optimization Card

Displays Rule Engine output, including rule ID, severity, description, recommendation, and documentation link.

## Execution Tree

Shows optional EXPLAIN data and clearly distinguishes physical execution details from the logical graph.

## AI Card

Displays optional explanation, suggestions, confidence or caveats, and AI availability state.

## Status Bar

Shows parser, dialect, AI, graph version, warning count, and application status.

## Theme Toggle

Allows switching between Dark and Light themes and persists the preference locally.

## Component Requirements

Components must use semantic tokens, expose accessible names, support keyboard interaction, and provide loading, empty, error, and unavailable states where applicable.
