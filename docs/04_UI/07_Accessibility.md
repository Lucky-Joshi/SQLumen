# Accessibility

## Goals

Target WCAG AA conformance for supported application surfaces.

## Keyboard Navigation

All controls, tabs, graph nodes, dialogs, and panels must be reachable and operable with a keyboard. Focus order follows the visual and task order.

## High Contrast

High-contrast presentation must preserve borders, text, controls, warnings, and node distinctions.

## Reduced Motion

Respect the user's reduced-motion preference and provide static alternatives to nonessential animation.

## Screen Readers

Provide accessible names and roles for all controls. Graph nodes should expose their type, label, relationships, and warning state in an understandable text representation.

## Color Blind Friendly

Node shapes, labels, patterns, and icons must differ in addition to color. Status messages must never communicate meaning through color alone.

## Content and Focus

- Maintain visible focus indicators.
- Use clear error and status announcements.
- Keep text readable at increased zoom.
- Ensure dialogs and tabs have predictable focus management.
