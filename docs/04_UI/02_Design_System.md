# Design System

## Principles

- Simple
- Developer-first
- Minimal
- Information-dense
- Consistent across web, desktop, and VS Code surfaces

## Border Radius

- Cards: `12px`
- Buttons: `10px`
- Nodes: `16px`

## Shadows

- Light theme: small elevation with restrained contrast
- Dark theme: subtle glow without reducing text contrast

## Typography

- Headings: Inter Bold
- Body: Inter Regular
- Code: JetBrains Mono

## Spacing

Use an 8px-based spacing grid:

`4`, `8`, `12`, `16`, `24`, `32`, `48`

## Content Density

Prefer compact, scannable information panels. Dense views must retain readable line height, clear grouping, and sufficient focus spacing.

## Responsive Behavior

The editor, graph, and analysis panels should collapse progressively rather than overlap. Secondary panels may become tabs or drawers on narrow screens.
