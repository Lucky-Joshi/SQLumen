# Target Users

## Primary Audience

### Students

Learning SQL fundamentals.

---

### Interview Candidates

Preparing for SQL coding interviews.

---

### Backend Developers

Understanding legacy queries.

---

### Data Analysts

Reviewing analytical SQL.

---

### Database Beginners

Learning joins and execution order.

---

## Secondary Audience

- Technical Trainers
- Coding Bootcamps
- Open Source Contributors
- Freelance Developers

---

## Not Intended For

- Database Administrators requiring production monitoring
- Enterprise database management
- Query execution benchmarking
- Database administration
- Cloud database management

---

## User Goals

Users typically want to:

- Understand queries quickly
- Learn SQL
- Improve performance
- Debug complex joins
- Prepare for interviews

SQLUMEN focuses on these goals.
