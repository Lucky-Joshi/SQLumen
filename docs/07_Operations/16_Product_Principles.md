# Product Principles

1. Deterministic before Intelligence.
2. Privacy by default.
3. Explain before optimize.
4. Never guess.
5. Offline first.
6. Educational by design.
7. Accessible by default.
8. Modular architecture.
9. Honest confidence levels.
10. Intelligence enhances, never replaces deterministic analysis.

When a future feature is ambiguous, evaluate it against these principles before implementation.
