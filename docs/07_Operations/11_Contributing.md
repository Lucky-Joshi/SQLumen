# Contributing

```text
Fork
    ↓
Branch
    ↓
Implement
    ↓
Tests
    ↓
Documentation
    ↓
Pull Request
```

Code review is required. Do not commit directly to `main`.

Contributors should:

- Explain the problem and intended behavior.
- Add or update tests.
- Update directly related documentation.
- Run lint, type-check, and targeted tests.
- Avoid unrelated refactors.
- Remove secrets and real user data from examples.
