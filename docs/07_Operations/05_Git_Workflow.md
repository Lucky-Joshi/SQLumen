# Git Workflow

## Branch Names

- `main`
- `develop`
- `feature/*`
- `bugfix/*`
- `hotfix/*`
- `release/*`

## Commit Format

Use concise Conventional Commit prefixes:

- `feat:`
- `fix:`
- `docs:`
- `refactor:`
- `test:`
- `perf:`
- `chore:`

Commits should be focused, explain the user-visible or engineering impact, and avoid unrelated changes.
