# Explanation Modes

## Beginner

- Use simple language.
- Define technical terms.
- Provide examples.
- Minimize jargon.
- Explain the logical flow step by step.

## Intermediate

- Use technical explanations.
- Describe logical execution order.
- Explain join logic.
- Connect warnings to graph nodes.

## Expert

- Use database terminology.
- Discuss optional execution-plan evidence.
- Explain optimizer considerations.
- Describe trade-offs and uncertainty.

Modes change presentation depth, not the underlying deterministic analysis.
