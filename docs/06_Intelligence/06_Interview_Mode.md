# Interview Mode

## Purpose

Help users prepare for SQL interviews using the deterministic graph and analysis as context.

## Generated Questions

- Why use a `LEFT JOIN` here?
- Can this query use `EXISTS`?
- What affects the query's complexity?
- What index information would be needed?
- What alternative approaches are possible?

## Difficulty

- Easy
- Medium
- Hard
- FAANG style

Questions are generated from Graph JSON, warnings, statistics, and available schema context, not directly from unprocessed raw SQL.
